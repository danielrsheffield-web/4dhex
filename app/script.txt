The basic structure of a tutorial slide:
{{int}} <- slide key, with the slide's number between brackets
True/False <- indicates whether the board must be reset for this slide
int <- size of board to create. skipped if the board isn't reset
list <- sequence of moves to make on redrawn board. skipped if board isn't reset moves are split by | and each move starts with "b" or "r" to indicate player, then a comma spliced coordinate list
True/False <- indicates if the coordinate order must be set for the new slide
list <- new coordinate order. skipped if not being set
True/False <- indicates if any hexes must be marked
list <- sequence of hexes to mark. skipped if no hexes are to be marked
text <- full text to be displayed

The basic rule is that a hex is adjacent to another if you can get from one to another by increasing some coordinates by 1 and leaving others alone, or by decreasing some coordinates by 1 and leaving others alone, but not mixing increasing and decreasing coordinates. As such, on the boards above the hex in question, the hexes with a position directly above the original hex's position, and one the boards below, the positions below are adjacent.
